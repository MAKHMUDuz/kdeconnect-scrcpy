# kdeconnect-scrcpy - Katkıda Bulunma

Bu projeye katkıda bulunmak için teşekkür ederiz!

## 🛠️ Geliştirme Ortamı
- Qt6 ve QML bilgi gerektirir
- scrcpy cihaz yönetimi için Android cihazı gerekir
- Projeyi çalıştırmak için: `qmake && make`

- [Help Wanted](https://github.com/MAKHMUDuz/kdeconnect-scrcpy/issues?q=is%3Aissue+is%3Aopen+label:"help wanted") etiketli issue'lar daha deneyimli katılımcılar için

## 🔀 Pull Request Akışı
1. Bu depoyu fork edin
2. `main` dallarından `feature/short-desc` dalı oluşturun
3. Değişiklikleri yapın ve test edin
4. Commit mesajlarını konvensiyonel formatta tutun
5. PR oluşturun, `Closes #issue-number` ifadesiyle
